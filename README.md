# 🗓️ MiHorario - Planificador Académico Interactivo

Aplicación web desarrollada con **React.js** que permite a los estudiantes organizar visualmente sus clases semanales. Incluye las funcionalidades de **arrastrar y soltar**, **modo oscuro**, **exportación a PDF**.

## Funcionalidades

-  **Agregar, eliminar y mover clases** entre días
-  **Arrastrar y soltar clases** con `react-dnd`
-  **Modo claro/oscuro**
-  **Exportar horario en PDF**
-  **Estilos personalizados por color de clase**
-  **Detección de clases solapadas** (permite guardar de todas formas)
-  **Persistencia automática con LocalStorage**
-  **Diseño responsive**

## Tecnologías usadas
- **React.js
- **React DnD
- **Framer Motion
- **jsPDF
- **LocalStorage
- **CSS Modules
